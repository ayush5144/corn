## 2. Bugs found and fixed today

| Bug | Cause | Fix |
|---|---|---|
| Blank/black areas on pages | Always-on animation layer around the WebView | Layer only during the Flush animation |
| App jumped to the new-tab page | WebView page process crashed (2 GB emulator), no handler | `onRenderProcessGone` + reload card; emulator → 4 GB |
| Address bar showed the placeholder | Edit-state tied to remembered keys | Show URL when not editing; edit text on focus |
| Extra empty tab when a link opened Corn | Cold start always created a new-tab page | Load the link in the first tab |
| "new group" shown twice | Hint text read as a duplicate | Separate labels for "new tab group" / "in group · name" |
| http sites wouldn't load | Android blocks cleartext by default | Allowed for the browser |
| Scripted pop-ups not counted | WebView dropped them before Corn saw them | All pop-ups reach Corn |

**Not Corn bugs:** DuckDuckGo's "Get it on Google Play" (mobile page), dark vs light page (app theme vs emulator theme), sheets opening "by themselves" (real taps arriving at the top of the screen that the test scripts didn't send).

| Offline starter list | Nice to have | Only matters on a first launch with no internet |
| Fingerprinting protection | Nice to have | Real privacy gain, more testing needed |

| Password store | v1.1 | Founder decision |

Already done from the privacy list: third-party cookies blocked, mixed content blocked, WebView metrics opt-out, no backups.
