# 01 — Privacy & Efficiency Audit (2026-11-01)

> **For developers and AI Agents-Claude and Codex etc.** This file helps developers understand the code. The code is always the source of truth: if this file and the code disagree, trust the code. This file may be out of date.
>
> **Created:** 2026-11-01 · **Last updated:** 2026-11-01, 14:01 IST

What Corn stores, logs, sends and costs, checked against the code and measured on the emulator (Pixel 8 image, Android 16, 4 GB RAM). Commit audited: `b349d6b`; updated for later commits up to `f6dc779` (same day).

## 1. What Corn stores

| Where | Contents | Browsing data? |
|---|---|---|
| `corn.db` (SQLite) | Vault (Collections, items, tags); key-value: `keep_list`, `site_shields`, `kept_session` | Yes, by design: only what the user saved, the sites they chose, and the open tabs of a Kept Session. Flush deletes `kept_session`. |
| Settings file (`corn_settings`) | Settings, PIN salt + PBKDF2 hash, `total_blocked`, `total_popups`, `left_at`, `last_activity_at` | No. Two plain counts and two timestamps |
| `ads-v1.dat`, `trackers-v1.dat` | Compiled filter lists | No |
| `corn_engine` settings | Time of the last filter-list refresh | No |
| WebView storage (`app_webview/`, `cache/WebView/`) | Cookies, site storage, HTTP cache | Yes. Wiped by Flush (Keep List cookies restored) |
| Tab previews | Memory only, ~0.25 MB each | Never written to disk |

**Not stored anywhere:** which requests, trackers or sites were blocked; browsing history beyond the Kept Session's open tabs; search queries.

## 2. What Corn logs (Android system log)

| Log line | Contains URLs? |
|---|---|
| Engine built (line count) / cache unreadable / engine failed | No |
| Page process gone (crashed true/false) | No (a URL was removed in this audit) |
| WebView too old for element hiding | No |
| Create collection failed (exception) | No |

Page console messages (which can contain URLs, e.g. from the cookie-banner script) are swallowed by `onConsoleMessage` and never reach Android's log.

No analytics, no crash reporting, no remote logging. Rule added to `AGENTS.md`: never log URLs, titles, searches or site names.

## 3. What Corn sends

| Destination | When | Contains browsing data? |
|---|---|---|
| easylist.to | First launch, then every 4 days on Wi-Fi (list refresh) | No: a plain file download |
| Cookie-banner script | Never: autoconsent runs inside the page and contacts no server | — |
| Websites the user visits | Browsing | The visit itself (unavoidable); third-party cookies blocked; trackers blocked |
| Google (WebView usage metrics) | Never: opted out with `android.webkit.WebView.MetricsOptOut` | — |
| Google Safe Browsing | When pages load, if the Settings switch is on (default on, explained in onboarding) | Shortened, hashed URL prefixes, not full URLs |

## 4. Size and memory (measured)

| Measure | Value |
|---|---|
| Release APK (R8, phones-only native library) | **8.6 MB** (6.0 MB before the built-in starter lists and cookie-banner script were added) |
| Debug APK | 21.3 MB |
| Installed code, debug build | 21.8 MB (release is smaller; Android adds compiled code over time) |
| App data after first run | 11.0 MB: block lists 5.9 MB + WebView 4.7 MB + cache 0.2 MB (grows with browsing, cleared by Flush) |
| Native library (Rust: adblock-rust ×2 + SQLite) | 4.4 MB per ABI |
| App process memory, 1 tab | 139 MB PSS (Java 29 MB, native 31 MB); the page runs in WebView's separate process |
| 10 live tabs (spike, before tab freezing) | ~1.05 GB → reason for the live-tab rule |

## 5. Fixes made in this audit

| Issue | Fix |
|---|---|
| Crash log line included the page URL | URL removed |
| `http://` sites could not load (`ERR_CLEARTEXT_NOT_PERMITTED`) | `usesCleartextTraffic="true"` (HTTPS upgrade still planned) |
| Scripted pop-ups dropped by WebView, not counted, ignored the per-site switch | All pop-ups now reach `onCreateWindow` |
| Disk write on every tap (`last_activity_at`) and on every batch of blocks (totals) | In memory; written once when leaving Corn |
| Inactivity timer woke the app every 30 s even when off | Only runs while the setting is on |
| Unused session counter and engine status | Removed |
| Tab previews ~0.5 MB each | ~0.25 MB (scale 0.25, RGB_565) |
| Release shipped the emulator-only x86_64 library and unshrunk code | Release: arm64 only, R8 + resource shrinking |
| WebView usage metrics could go to Google | Opted out |
| Page console messages copied into Android's log (can include URLs) | `onConsoleMessage` returns true (later the same day) |

## 6. Verified numbers are real

Test page with exactly 5 known ad/tracker requests, 3 normal files and 1 scripted pop-up:
- Shield: **5**. Home stats: **5 blocked, 1 pop-up stopped**. Same in debug and release (R8) builds.
- Server log: the 3 normal files loaded, so nothing legitimate was blocked.
- Each blocked request increments the counter once, in the same branch that blocks it.
