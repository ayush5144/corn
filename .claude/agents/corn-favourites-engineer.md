Read first: `AGENTS.md`, `GLOSSARY.md` (Vault, Favourite, Collection), the decision log's latest round (`docs/01-product/02-decision-log.md`, search "Favourites (founder, A+)" and the "Changed while building" note under it), and the mockup **`mockups/favorites.html`**, frames "A+", "View all · bottom drawer" and "New user" (open it in a browser or read the HTML). ## What the founder decided
- A **favourite is its own list, not a flag on a Vault link** ("someone might want to favourite a home page but not save it to the Vault"). No separate bookmarks folder: the Vault is for saving, favourites are quick-access tiles. Favourites **survive every Flush** and are **shown without the PIN**; export and the Vault's PIN rules don't change.
- **New-tab page, under the search box:** one horizontal row. The **Vault tile is fixed at the start** (thin divider after it); **favourites scroll sideways** after it (56 dp tile, 16 dp corners, the site's icon or its coloured letter via `C.forHost`, the name as label), and a **"+ Favourite" tile last** (same size, transparent, 1.5 dp dashed border in `C.Line`, "+" in `C.Muted`, label "Favourite"), which opens the Add sheet. Tile columns ~62 dp so the **Vault and 4 favourites fit on a 360 dp phone** (20 dp page padding) without cut-off; the "+" tile may scroll. With 5 or more, the tile at the edge is cut off so it's clear the row scrolls. **No header, no Edit button.**
- **"View all"** (exactly that text, accent colour) is a text link **under the row, aligned right**, shown **only with 5 or more favourites**. No other link under the row. It opens a **bottom drawer** (Corn's usual bottom sheet) over the new tab, not the Vault (so no PIN): title "Favourites" with the count in brackets right after it, " (N)" in `C.Muted`, and a **"+ Add"** text button (accent) on the right; every favourite as the same tiles, **4 across**, in favourite order. Tap a tile opens the link in the current tab and closes the drawer; long-press gives the same Remove / Move left / Move right sheet. Keep the grid in its own composable.
- **No favourites yet:** the Vault tile and the "+ Favourite" tile, side by side, centred. No hint text, no "View all".
- **Favourites replace the "recent Vault links" tiles** that the new tab showed (`recentItems(3)` when the Vault lock was off). Remove that code.
- **Visible even while the Vault is locked.** When a favourite is added, the toast or sheet line says "Favourites show on the new tab, even while the Vault is locked."
- **Adding:** (1) Vault item rows have no ⋮ menu; long-press opens the delete sheet. Put "Add to favourites" (copies the link's address and title into favourites) / "Remove from favourites" (when that address already is one) in that long-press sheet next to Delete, matching its look. (2) The Add sheet (from "+ Favourite" or the drawer's "+ Add"): Address field (required; accepts "example.com"; normalised like the address bar, with corn-url's clean and https upgrade) and an optional Name field (default: the host), then Cancel / Add (Add coloured, disabled until the address is valid). From the drawer, adding returns to the drawer showing the new tile.
- **Long-press a tile** (row or drawer) → a small sheet with **Move left**, **Move right**, **Remove from favourites**. Tapping a tile opens the link in the current tab (like the old recent tiles did). No drag-and-drop, no "Vault filtered to favourites" screen.
- **Icons:** the site's real icon, letter as fallback. **One per site** (host without "www."), not per favourite, 64×64 PNG (a few KB). Only from the in-memory icon WebView gives Corn for a page it shows: when a favourite is added while an open tab on that site has its icon, and whenever a page of a favourite's site loads with an icon and the site has none yet (or one older than ~30 days). **Never fetch an icon** with a request of Corn's own. Never kept for anything that isn't a favourite (history stays letters); deleted when no favourite on that host remains; survives Flush like favourites. Shown centred on the tile (~30 dp).

## Tasks
1. **Rust, `corn-vault`:** database **version 5** adds two tables, no change to `items`: `favorites (id INTEGER PRIMARY KEY, url TEXT NOT NULL UNIQUE, title TEXT NOT NULL, pos INTEGER NOT NULL, created_at INTEGER NOT NULL)` and `favorite_icons (host TEXT PRIMARY KEY, png BLOB NOT NULL, updated_at INTEGER NOT NULL)`. New databases and the 4 → 5 upgrade get them from `SCHEMA`; keep every older upgrade path intact. Methods: `add_favorite(url, title)` (appends; an existing url keeps its place and takes a non-blank new title), `remove_favorite(id)` (also drops icons of hosts with no favourite left), `favorites()` (ordered by pos), `move_favorite(id, delta)` (no-op at the ends), `set_favorite_icon(host, png)` (only if a favourite is on that host), `favorite_icon_wanted(host, max_age_ms)`, `favorite_icons()`, `site_host(url)`. Unit tests: the 4 → 5 upgrade on a real version-4 database, add/duplicate/remove/order/move/ends, icon upsert, shared host, cleanup when the last favourite on a host goes.
2. **FFI:** expose those. Regenerate bindings the way the project already does (read `scripts/` and the Gradle setup; don't hand-edit generated files).
3. **Android:** `CornData` wrappers (bump `vaultVersion` on change so the UI refreshes), the new-tab row with "+ Favourite", the tile long-press sheet, the Vault long-press sheet entries, the Add sheet, the View all bottom drawer, icon capture (`TabHost` hook from WebView's icon; scale to 64×64 PNG). Use existing components (`QuickTile`, `CornIcon`, `T`, `Field`, `BigButton`, sheet patterns, `Corners`). Light and dark themes (keep see-through icons legible on both).
4. **Verify (all required):** `cd core && cargo test`; `cd android && ./gradlew :app:testDebugUnitTest :app:assembleDebug` with `JAVA_HOME="/Applications/Android Studio.app/Contents/jbr/Contents/Home"` and `ANDROID_HOME=~/Library/Android/sdk`. On the emulator (app `app.cornbrowser`, Vault PIN 1234; `scripts/qa/device.py` has helpers): add favourites both ways; with exactly 4, none is cut off and no "View all"; with 5, the 5th is cut off and "View all" shows under the row on the right and opens the drawer (4 across, count, "+ Add", no PIN); long-press Move left/right and Remove work; the row shows with the Vault locked; the empty state; a favourite added from an open page shows its icon, one added by typing shows a letter until its site is visited; upgrading from the current installed build keeps Vault data (install over it, don't uninstall). Screenshot dark and light and Read them. Run `bash scripts/qa-run.sh` (known flaky: `search-result-link-menu` and the first check). Leave the emulator with your final build, exactly 6 favourites (wikipedia.org, duckduckgo.com, github.com, openstreetmap.org, mozilla.org, archive.org), each visited so its icon shows, on a new tab.
5. **Docs:** `docs/01-product/03-features.md` (Favourites, with icons), `docs/01-product/01-prd.md` (reword "The Vault replaces bookmarks": no separate bookmarks folder, the Vault is for saving, favourites are quick-access tiles; a Favourites row ✅), `docs/01-product/02-decision-log.md` (Round 26 note: favourites are their own list), `docs/02-technical/10-storage.md` (database version 5, favourites and icons), `GLOSSARY.md` (add **Favourite**: a link shown as a tile on the new tab, its own list, not a Vault Item; adjust the Vault entry's "Avoid: favourites" note), a checklist section "Favourites" with ticked rows whose "done when" is true, a `docu.md` entry; run `python3 scripts/doc-banner.py` and revert files whose only change is the banner date.
